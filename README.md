# 🔌 Verilog Basic Circuits (Vivado)

## 📌 Overview

This repository contains fundamental digital circuits implemented using **Verilog HDL** and simulated in **Xilinx Vivado**.
It is designed for beginners to understand digital logic design, HDL coding, and simulation workflows.

---

## 🚀 Circuits Implemented

* AND Gate
* OR Gate
* NOT Gate
* NAND Gate
* Half Adder

---

## ⚙️ Tools & Technologies

* Verilog HDL
* Xilinx Vivado
* Digital Logic Design

Each circuit is verified using a **testbench** and simulated in Vivado.
The waveform output confirms the correctness of the implemented logic.
